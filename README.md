# Guia de Visual Editing Helpers

Um guia de referência com **21 funcionalidades de edição visual**, cada uma acompanhada de um exemplo prático e um prompt pronto para usar com IA.

## 🎯 Sobre o projeto

Este projeto é uma página HTML estática que documenta os principais *helpers* usados em ferramentas de edição visual (como editores de jogos, construtores de UI e ambientes de design). Cada cartão da página traz:

- **Nome e termos relacionados** ao helper
- **Exemplo simples** explicando o conceito
- **Prompt pronto** para você copiar e enviar a uma IA pedindo a implementação

A frase-base sugerida é: *"Para eu ajustar este app, eu quero que você crie..."*

## 🚀 Como usar

1. Abra o arquivo `index.html` diretamente no navegador — não é necessário nenhum servidor ou build.
2. Navegue pelos 21 cartões.
3. Clique em **"Copiar prompt"** em qualquer cartão para copiar o prompt pronto.
4. Cole o prompt em uma IA (como o GitHub Copilot, ChatGPT ou similar) e descreva seu projeto.
5. Para copiar todos os 21 prompts de uma vez, clique em **"Copiar todos os prompts"** no topo da página.
